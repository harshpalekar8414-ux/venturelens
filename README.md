# VentureLens

> **AI-Powered Startup Research & Investment Intelligence Platform**

VentureLens transforms unstructured, multi-source web information into structured, source-backed company intelligence, cap tables, risk matrices, and institutional investment memos.

---

## 1. Project Status

- **Current Milestone:** **Milestone M0 — Project Infrastructure** (Completed)
- **Status:** Foundations established. FastAPI backend, PostgreSQL 16 + pgvector container (with automated extension initialization), and Next.js 15 terminal frontend configured and verified.
- **Next Milestone:** Milestone M1 — Backend Data Core & Alembic Models.

## 2. Core Principle: Four-Tier Epistemic Fact Integrity

VentureLens enforces a strict evidence-traceability standard:
> *"Every externally sourced factual claim must be traceable to an evidence record. Claims without sufficient supporting evidence must be explicitly marked unsupported/uncertain or excluded from factual output."*

Every data point in the system is classified into one of four tiers:
1. **`FACT`**: Verifiable data extracted from crawled sources with exact verbatim quote and chunk bindings.
2. **`CALCULATED`**: Deterministic metrics computed via algorithms (CAGR, runway, valuation step-up multiples).
3. **`ASSUMPTION`**: Explicitly declared baseline model parameters with warning badges when data is missing.
4. **`AI_INTERPRETATION`**: Strategic synthesis (Investment Thesis, Moat scoring, Bull/Bear cases, DD questions) generated by Gemini 3.7 Flash grounded strictly in verified facts.

```
       ┌─────────────────────────────────────────────────────────────┐
       │                        VentureLens                          │
       │                   Architecture Overview                     │
       └─────────────────────────────────────────────────────────────┘
                                      │
         ┌────────────────────────────┴────────────────────────────┐
         ▼                                                         ▼
┌──────────────────┐                                     ┌──────────────────┐
│  Tier 1: FACTS   │◄── Grounded Web Search & Crawling   │  Tier 2: CALCS   │◄── Deterministic
│  Source-linked   │                                     │  CAGR, Runway    │    Math Engine
└────────┬─────────┘                                     └────────┬─────────┘
         │                                                        │
         └────────────────────────────┬───────────────────────────┘
                                      ▼
                        ┌───────────────────────────┐
                        │   Tier 3: ASSUMPTIONS     │◄── Explicit Default
                        │   Industry Benchmarks     │    Parameters
                        └─────────────┬─────────────┘
                                      ▼
                        ┌───────────────────────────┐
                        │ Tier 4: AI INTERPRETATION │◄── Gemini 3.7 Flash Reasoning
                        │ Thesis, Moat, Bull/Bear   │    (Strict Evidence Grounding)
                        └───────────────────────────┘
```

- **Frontend:** Next.js 15 (App Router, React 19, TypeScript, Tailwind CSS, Lucide icons).
- **Backend:** Python 3.11+ / FastAPI (AsyncIO, Pydantic v2, SQLAlchemy 2.0, Alembic).
- **Database:** PostgreSQL 16 + `pgvector` (Unified relational entities and HNSW vector index).
- **AI Models:** Google Gemini API (`gemini-3.7-flash` default with thinking budget, `gemini-embedding-2` for embeddings).
- **Web Retrieval:** Pluggable `SearchProvider` (Tavily default, Mock fallback) + `httpx` / `trafilatura` crawler with SSRF pre-flight DNS filtering.

## 4. Local Setup & Quick Start

### Prerequisites
- [Docker & Docker Compose](https://www.docker.com/)
- [Python 3.11+](https://www.python.org/)
- [Node.js 20+ & npm](https://nodejs.org/)

### Step 1: Clone Repository & Configure Environment
```bash
cp .env.example .env
```

Review `.env` and set your preferred keys (defaults use mock providers for local offline testing).

---

### Step 2: Start PostgreSQL (with pgvector)
```bash
docker compose up -d postgres
```

> **Note:** The `docker-compose.yml` mounts `scripts/init_db.sql` into `/docker-entrypoint-initdb.d/`, automatically enabling both `uuid-ossp` and `vector` extensions upon fresh database creation.

Verify that the database container is running and healthy:
```bash
docker compose ps
```

---

### Step 3: Start the FastAPI Backend
```bash
cd backend

# Create and activate virtual environment
python -m venv .venv

# On Windows:
.venv\Scripts\activate
# On macOS/Linux:
# source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Start backend server
uvicorn app.main:app --reload --port 8000
```

- **API Root:** [http://localhost:8000/](http://localhost:8000/)
- **Swagger Documentation:** [http://localhost:8000/api/v1/docs](http://localhost:8000/api/v1/docs)
- **Health Check Endpoint:** [http://localhost:8000/api/v1/health](http://localhost:8000/api/v1/health)

---

### Step 4: Start the Next.js Frontend
```bash
cd frontend

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to access the VentureLens terminal.

## 6. Environment Variables Reference

| Variable | Description | Default (Local Dev) |
| :--- | :--- | :--- |
| `ENVIRONMENT` | Runtime environment (`development`, `staging`, `production`) | `development` |
| `DATABASE_URL` | PostgreSQL connection string (`asyncpg`) | `postgresql+asyncpg://postgres:postgres@localhost:5432/venturelens` |
| `EMBEDDING_MODEL` | Gemini embedding model identifier | `gemini-embedding-2` |
| `EMBEDDING_DIMENSION` | Configurable vector dimensionality | `768` |
| `GEMINI_API_KEY` | Google Gemini API key | `mock_key_for_local_dev` |
| `GEMINI_EXTRACTION_MODEL` | Primary extraction model | `gemini-3.7-flash` |
| `GEMINI_SYNTHESIS_MODEL` | Deep synthesis model | `gemini-3.7-flash` |
| `GEMINI_THINKING_BUDGET` | Thinking budget token cap for synthesis | `2048` |
| `SEARCH_PROVIDER` | Web search provider (`tavily`, `mock`) | `mock` |
| `SEARCH_PROVIDER_API_KEY` | Search API credentials | `mock_search_key` |
